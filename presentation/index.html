Multi-Robot Exploration and SLAM System

Purpose & Goals of ASCILAM

  • 🎯 Autonomous Multi-Robot Exploration

    Coordinate multiple robots for simultaneous environment exploration using frontier-based algorithms

  • 🗺️ Collaborative SLAM

    Create unified maps through cooperative simultaneous localization and mapping

  • 🚀 Intelligent Coordination

    Implement smart task allocation and collision avoidance between robots

  • 📡 Real-time Communication

    Enable seamless data sharing and command coordination via micro-ROS

  • 🔧 Scalable Architecture

    Support adding more robots with minimal configuration changes

  • 🚗 Motor Control

    L298N driver with PWM speed control and direction pins

  • 🛡️ Safety Systems

    Ultrasonic collision avoidance (25cm threshold) with emergency stop

  • 🎨 Visual Feedback

    RGB LEDs indicating robot status: Green (autonomous), Red (emergency), Blue/Yellow (turning)

  • 🔗 ESP32 Communication

    9600 baud UART for command and sensor data exchange

# Key ROS2 Nodes: roslaunch multirobot_nav multi_robot_launch.py • robot_coordinator - Task assignment & coordination • robot_controller (x2) - Individual robot control • multi_robot_slam - Collaborative mapping • micro_ros_agent (x2) - ESP32 communication bridges • tf2_static_publishers - Transform management
  • 📊 Data Flow: LiDAR → SLAM → Map → Coordinator → Goals → Controllers → Commands
  • 🔄 Update Rates: SLAM (5Hz), Coordination (0.5Hz), Control (10Hz), Safety (5Hz)
  • 🎯 Completion Criteria: 90% map coverage with 1.5m minimum robot separation
